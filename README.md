# Love Heart

A small Python script that draws a red heart on a black background using the turtle library.

## How it works
The heart shape is built from parametric equations (sine and cosine). The script goes through 6000 points of the curve and draws a line from each point to the center, so the heart is filled with red lines.
Based on a well-known parametric heart equation.
